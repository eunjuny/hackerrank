좋아, **힌트만** 깔끔하게 줄게! (정답 코드 아님)

## 핵심 아이디어

1. **3×3 매직 스퀘어(1~9)** 는 경우의 수가 **딱 8개**뿐이야.
   (Lo Shu 정방형의 회전/대칭 8가지)

2. **중앙은 항상 5**, **모서리는 짝수(2,4,6,8)**, **변의 가운데는 홀수(1,3,7,9)**.
   이 성질이 안 맞으면 반드시 바꿔야 해.

3. 목표는 입력 `s`를 8개 후보 중 하나로 바꾸는 **최소 비용**을 찾는 것.
   → 각 후보와의 **원소별 |차| 합**을 구해서 **최솟값**을 취하면 끝.

## 접근 절차

* 단계 1: 3×3 매직 스퀘어 **8개**를 미리 준비한다.
  (회전·대칭으로 생성 가능. 막히면 아래 스포일러 참고👇)
* 단계 2: 각 후보 `t`에 대해
  `cost = Σ |s[i][j] - t[i][j]|` (i,j = 0..2) 계산
* 단계 3: 모든 후보 중 **최소 cost**를 출력

## 자주 하는 실수

* 중앙이 5가 아닐 때 무시하고 진행 ⇒ 비용 계산 누락
* “서로 다른 1~9” 조건을 직접 체크하려고 함 ⇒ 불필요 (후보가 이미 만족)
* 한두 후보만 비교하고 멈춤 ⇒ 반드시 **8개 전부** 비교

## (스포일러) 3×3 매직 스퀘어 8개

필요하면만 보자!

```
[ [8,1,6], [3,5,7], [4,9,2] ]
[ [6,1,8], [7,5,3], [2,9,4] ]
[ [4,9,2], [3,5,7], [8,1,6] ]
[ [2,9,4], [7,5,3], [6,1,8] ]
[ [8,3,4], [1,5,9], [6,7,2] ]
[ [4,3,8], [9,5,1], [2,7,6] ]
[ [6,7,2], [1,5,9], [8,3,4] ]
[ [2,7,6], [9,5,1], [4,3,8] ]
```

## 구현 팁 (Java15용 스켈레톤)

* 2중 루프로 `|s[i][j] - t[i][j]|` 누적
* 후보 8개 순회하며 `minCost` 갱신

이 로드맵대로 하면 바로 통과 가능해. think about it step-by-step
